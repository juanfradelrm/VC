# Funciones básicas de OpenCV

## Descripción del trabajo

En este repositorio hay una colección de ejecicios prácticos realizados con la biblioteca OpenCV en Python, con un enfoque en el procesamiento y la manipulación de imágenes. Las tareas realizadas son:

1. **Recuento de píxeles blancos por filas en una imagen**
2. **Determinar las filas y columnas con el máximo número de pixeles blancos** aplicando umbralizado a la imagen.
3. **Crear un demostrador que permita exhibir distintos procesamientos de la imagen** de una webcam.
4. **Propuesta de interpretación de la imagen** inspirada en distintos videos.
